# Frontend Domain

前端是 Memory OS 的第一优先领域，但不是唯一领域。

## 关注点

- 真实用户流程。
- loading / error / empty / disabled 状态。
- 组件边界与状态归属。
- 设计系统复用。
- 可测试性与回归保护。

当前端任务包含“读取原型/设计稿/iframe + 后续开发/还原页面”时，先读取 `workflows/frontend-prototype-driven-development.md`，再进入代码实现或浏览器读取。

## Workflows

- `workflows/frontend-regression-verification-strategy.md`：前端代码修改后的回归验证分层策略和验证副作用控制。
- `workflows/frontend-prototype-driven-development.md`：按 CoDesign / Lanhu / Figma / Axure 等原型开发页面前，先提取字段/数据、交互/状态、API 边界和结构性视觉布局约束。
