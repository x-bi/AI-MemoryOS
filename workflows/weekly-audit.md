# Weekly Audit Workflow

## Read

- `STATUS.md`
- `proposals/pending/`
- `proposals/future-directions/`（只检查是否需要专题回顾，不作为待晋升 proposal）
- `evals/router-test-cases.md`
- `evals/skill-trigger-test-cases.md`
- `skills/catalog.md`

## Check

- pending 是否堆积。
- future directions 是否需要专题回顾或拆出具体 proposal。
- 是否有重复或冲突 proposal。
- router 是否臃肿。
- skills description 是否重叠。
- 是否有项目私有内容误入全局。

## Output

只输出 audit report 或 cleanup proposal。不要直接删除正式内容。
