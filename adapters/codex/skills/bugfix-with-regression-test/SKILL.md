# Bugfix With Regression Test

## Workflow

1. 复现或定位 bug。
2. 找根因，不只改表象。
3. 做最小修复。
4. 补回归测试或说明无法补的原因。
5. 验证修复。
6. 若有跨项目经验，只提示是否需要沉淀，不自动写入 Memory OS。
