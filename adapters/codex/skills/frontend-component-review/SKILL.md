# Frontend Component Review

## Focus

- 主流程是否可用。
- loading / error / empty / disabled 是否覆盖。
- 重复提交、竞态更新、状态泄漏。
- 是否复用已有组件和设计系统。
- 是否有必要测试。

## Output

优先列问题和风险，再给修复建议。
