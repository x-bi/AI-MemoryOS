用户明确要求：复盘、沉淀、写入记忆、生成 proposal、更新 Memory OS。

## When not to use

普通编码、解释、排错、review 不使用。

1. 读取 `C:\Users\btf\AI-MemoryOS\_index.md`。
2. 只读取直接相关页面。

5. 生成 pending proposal。
6. 不直接修改正式规则。
