# Advanced URI Usage

用于从外部打开 Memory OS 中的 Obsidian note。

## 常用链接

打开 pending dashboard：

```text
obsidian://advanced-uri?vault=AI-MemoryOS&filepath=dashboard%252Fpending-proposals.md
```

打开 skills dashboard：

```text
obsidian://advanced-uri?vault=AI-MemoryOS&filepath=dashboard%252Fskills.md
```

## 注意

Advanced URI 只负责跳转，不负责记忆晋升。正式修改仍走 pending proposal 和 Git diff。
