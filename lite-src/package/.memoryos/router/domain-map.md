# Lite Domain Map

| Signal | Domain | Read |
|---|---|---|
| UI, component, form, page, interaction, state | frontend | `.memoryos/domains/frontend/README.md` |
| unit test, regression, E2E, coverage | testing | `.memoryos/domains/testing/README.md` |
| API, auth, integration, database | backend | `.memoryos/domains/backend/README.md` |

| CI, deployment, pipeline, environment | devops | `.memoryos/domains/devops/README.md` |
| secret, permission, vulnerability, dependency risk | security | `.memoryos/domains/security/README.md` |

When no domain is clear, handle the task as general engineering work. Do not expand reads just to search for a domain.
