# Audit Logs

每周或专项 Memory OS 审计记录放在本目录，文件名使用 `YYYY-MM-DD.md`。

审计记录用于保存治理证据链，而不是沉淀新规则本身。新经验仍先进入 `proposals/pending/`，通过审核后再晋升到正式 rules / router / skills / evals。

建议每条记录至少覆盖：

- Pending proposals 数量和处理动作。
- Duplicates / conflicts / stale content。
- Adapter drift：Codex、Claude、MCP、Obsidian 入口是否仍一致。
- Eval gaps：本次发现但尚未覆盖的路由或 skill 触发样例。
- Follow-up actions：下一次审计前需要完成的动作。
