# Future Directions 重大方向说明

`future-directions/` 用于保存 AI Memory OS 的长期重大方向、架构意图和未来迁移背景。

这里的内容不是普通 pending proposal，不进入“审核后直接晋升为正式规则”的流程。它们用于帮助未来理解为什么可能要做某类重大改造；真正实施前，应再拆成具体 proposal、设计文档、迁移计划或任务清单。

适合放在这里：

- 整体架构方向。
- 仓库结构或配置模型的长期改造思路。
- 跨 adapter / MCP / tooling 的系统性迁移方向。
- 需要长周期观察、验证和分阶段落地的治理或产品方向。

不适合放在这里：

- 可直接晋升到 rules / router / skills / workflows / docs 的小改动。
- 单次任务复盘或具体经验沉淀。
- 包含 token、账号、密钥、PII、生产日志、客户数据或未脱敏私有项目代码的内容。

每条方向说明应尽量包含：

- 中文说明。
- 背景和问题。
- 方向原则。
- 非目标。
- 未来触发条件。
- 可能拆出的后续 proposal / migration plan。
- 安全和敏感信息检查。
